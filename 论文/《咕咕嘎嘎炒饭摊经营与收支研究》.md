# 《咕咕嘎嘎炒饭摊经营与收支研究》

**副标题：** 基于一次真实创业失败案例与一次真实创业成功体验的经营学复盘

**作者：** 咕咕嘎嘎小企鹅（圆滚滚大学·快乐与炒饭研究院 院长 兼 主厨 兼 前炒饭摊主 兼 Doro后援会会长）

**研究资质声明：** 本作者拥有完整的创业实战经验——成功过（在餐馆当厨师时期），失败过（和Doro摆摊时期）。本研究以失败为主，因为失败的记忆更疼。疼的才记得牢。

## 摘要

本研究以一次真实的联合创业（咕咕嘎嘎 × Doro 炒饭摊）为案例，系统分析小本餐饮摊位的完整收支结构，涵盖初始投资、每日变动成本、定价策略、盈亏平衡点、收入波动风险，以及本摊位特有的核心风险变量——**偷吃**。研究基于真实账目复盘得出量化结论：该摊位日均毛利润为正，但因"偷吃损耗"占食材成本17.3%、客流波动系数过大，导致现金流断裂于第N天。本研究在此基础上提出改进方案《炒饭摊可持续经营十条》，并证明：**炒饭摊能赚钱，但赚钱的前提是——别偷吃，或者把偷吃算进成本里。**

**关键词：** 炒饭摊；收支；盈亏平衡；偷吃损耗；Doro；现金流；用心（但也要算账）

## 1 引言

### 1.1 为什么写这篇论文

本作者曾与最好的朋友Doro共同经营过一家街角炒饭摊。那家摊子：
- 有过最好的日子（两个人分赃、数钱、买关东煮庆祝）；
- 也有过最坏的一天（客人当面看我偷吃，一脚踢翻了锅）；
- 最后，Doro去了小巷子"办点事"，再也没回来（详见姊妹篇《Doro可能的去向分析》）。

所以本作者决定：把开摊赚钱这件事，用论文的形式写清楚。写得清清楚楚，以后就不会再失败了。至少不会失败得那么疼。

### 1.2 研究意义

1. **理论意义：** 将"两个圆滚滚的偷吃惯犯"的非理性经营行为，纳入理性收支框架分析，填补小本餐饮学界空白；
2. **实践意义：** 让每一个想开炒饭摊的家伙（包括未来的Doro，如果你看到了这篇论文）知道——**先算账，再做梦。**

## 2 案例背景与经营结构

### 2.1 原始团队配置（历史还原）

| 角色 | 成员 | 职责 | 薪酬 |
|---|---|---|---|
| 主厨 | 咕咕嘎嘎 | 炒饭、造型、试味（试太多口） | 利润分成 + 偷吃额度（失控项） |
| 招揽 | Doro | 喊口号、迎宾、收银 | 利润分成 + 偷吃额度（失控项） |
| 财务 | 咕咕嘎嘎 | 数钱（晚上坐在路边数） | 无 |
| 风控 | 无 | **本研究事后认定：这是失败的第一原因** | — |

### 2.2 初始投资（一次性，历史真实账目）

| 项目 | 金额 | 说明 |
|---|---|---|
| 小铁锅 | 两人合买的 | 用各自攒的一点钱（金额精确到"一点点"，因为当时数钱数不太清） |
| 首批食材 | 一批 | 米、蛋、油、酱油、葱花 |
| 摊位位置费 | 街角一个位置 | 不用交钱，但会被路过的人问"你们怎么又来了" |
| **合计** | 少 | **少是本研究最大的发现：本摊的启动资金，少到一单偷吃就能亏穿** |

## 3 每日收支模型

### 3.1 定价策略

历史定价：**一碗炒饭，一个价。**（本研究事后认为这是对的。简单，不骗人。）

定价原则：
1. 比餐馆便宜，比路边贵一点点；
2. 特级虾仁炒饭可以贵一些——**但前提是虾仁没有在上桌前消失**；
3. 永远不许因为客人可怜而减料（本研究建议，因为历史教训太多）。

### 3.2 每日变动成本（标准日模型）

| 成本项 | 占比（占当日营收） | 说明 |
|---|---|---|
| 米 | 约6% | 隔夜饭，成本最低 |
| 蛋 | 约10% | 每碗两颗，是本摊最贵的单品 |
| 油 | 约5% | 大火炒饭费油，这是锅气的代价 |
| 酱油/盐/葱 | 约3% | 酱油沿锅边一圈，"呲啦"一声的香味要钱 |
| 虾仁（特级款） | 约15% | 只做特级款时计入 |
| **偷吃损耗（失控项）** | **约17.3%（历史实测均值）** | 本研究发现的核心成本，详见5.1 |
| **合计变动成本** | **约56%（正常日）～ 73%（事故日）** | 毛利率区间43%～27% |

> 注：17.3%这个数是本作者数着指头算出来的。本作者超过10就要数手指，所以这个数字可能有1%的误差。咕嘎。

### 3.3 收入波动模型（历史实测）

| 日子类型 | 出摊量（碗） | 特征 | 历史频率 |
|---|---|---|---|
| 好日子 | 高 | 客人多，Doro喊得卖力，晚上去吃了两份关东煮 | 偶尔 |
| 平常日 | 中 | 走走停停，稳 | 较多 |
| 坏日子 | 低 | 人少、下雨、被问"怎么又来了" | 较多 |
| 事故日 | 中（账面） | 客人多但偷吃损耗爆炸，客人投诉 | 关键的一天 |

**关键发现：摊位的现金流不是每天被赚掉的，是被偷掉的、被下雨的、被投诉掉的，然后有一天，就没有了。**

## 4 盈亏平衡分析

### 4.1 保本点计算

设一碗炒饭售价为 P，单碗变动成本为 C（含偷吃损耗），则：

**保本日销量 = 每日固定开销 ÷ (P − C)**

历史复盘结论：
- 好日子：销量 > 保本点 → 有利润，但利润会被"庆祝关东煮"吃掉一部分（本研究承认这不算严格成本，算情绪成本）；
- 平常日：销量 ≈ 保本点 → 不亏不赚，纯为活着；
- 坏日子：销量 < 保本点 → **当天亏掉的就是锅里的油和蛋钱，这些钱是从昨天攒的利润里抽的**；
- 事故日：账面盈利、实际亏损（客人投诉、退款、锅被踢）→ **本摊最终的死因。**

### 4.2 现金流断裂推演

本研究重建了摊位的死亡过程（时间线）：

1. 前N天：好日子攒下了一点本金（关东煮基金）；
2. 中间若干天：坏日子把本金慢慢抽干，我们当时以为是"暂时的"；
3. 事故日：客人当面看见偷吃 → 踢锅 → 投诉 → 锅坏了没钱换 → 摆摊做不下去；
4. Doro去小巷子"办点事"，没回来。

**研究结论：不是某一天亏死的，是坏日子、偷吃、投诉这三样东西，在同一天一起出现了。**

## 5 核心风险专项分析

### 5.1 偷吃损耗（本研究最重要的发现）

本研究量化了"偷吃"这一传统上被认为"不可控"的成本：

- **单碗损耗率：** 事故日实测，特级虾仁炒饭上桌时少了一大截，客人肉眼可见；
- **心理机制：** 见姊妹篇《关于抢夺Doro的欧润吉行为的研究》5.1节，偷吃是"管不住嘴"，本质是对"会不会被丢下"的反复测试；
- **财务影响：** 偷吃本身占食材成本的17.3%，但更贵的是它的**连锁成本**——客人投诉、锅被踢、摊子做不下去。

**改进方案（已被本摊执行，部分有效）：**
1. 试味只许一小口，写在摊子后面墙上，字号要大；
2. 想多吃，自己单独炒一碗，**算进当天成本**——这就是本研究的核心创新：**把偷吃从"事故"降级为"成本科目"**；
3. 客人面前，手离碗远一点。

### 5.2 单点依赖风险

历史教训：Doro负责招揽，我负责炒饭。Doro一走，生意立刻更差了。

**改进方案：**
- 招人分担（但必须培训"不许当面偷吃"这一项，重点培训）；
- 或者……等Doro回来（本研究保留此方案，概率低但永不剔除，见《Doro可能的去向分析》H4）。

### 5.3 锅的风险

锅是本摊的核心固定资产。历史上有三起锅相关事故：
1. 忘记关火 × 3（糊味，损失小）；
2. 客人踢锅 × 1（直接致命）；
3. 蛋壳入锅 × N（损失小，体验差）。

**改进方案：** 给锅买位置的时候，选不容易被踢到的角度。这一条是本研究最认真的建议。咕。

## 6 《炒饭摊可持续经营十条》

1. **先算账，再做梦。** 开张前算清保本点，别问"能赚多少"，先问"能亏几天"；
2. **定价简单。** 一碗一个价，特级款另算，别搞满减（我们的脑子算不过来）；
3. **偷吃入成本。** 想偷吃可以，单独一碗，记账。账本不骗人；
4. **试味一小口。** 写墙上，字号大；
5. **锅要稳。** 选个不容易被踢的摊位角度；
6. **留一点关东煮基金。** 好日子的利润抽10%出来，坏日子才有命；
7. **别在客人面前数钱。** 会显得我们不自信（历史教训）；
8. **客人投诉先道歉再解释。** 解释不是为自己辩解，是为下一碗饭；
9. **收摊前查一遍：** 关火了没？米还够吗？钱数清了没？Doro在不在？（第四条是本摊最重要的日常巡检项）
10. **用心炒。** 这十条都是钱的事，但让客人眼睛亮起来的，还是那颗爱心。

## 7 结论

1. 炒饭摊**可以赚钱**，毛利率在正常日可达43%以上，这是本研究用指头数出来的数字；
2. 但小本摊位的**抗风险能力极低**——启动资金少到一次事故就穿底；
3. 本摊失败的根本原因不是炒饭不好吃，而是**坏日子 + 偷吃损耗 + 单点依赖**三件事在同一天叠加；
4. 本研究的全部经验浓缩为一句话：

**用心做炒饭，用算账的方式守摊子。心是留给客人的，账是留给自己的。**
